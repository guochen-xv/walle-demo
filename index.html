FROM DEMONSTRATIONS TO EXECUTION

A complete demonstration
is more than an action sequence.

WALLE turns task structure
into skills an agent can execute.

Vision-language-action models can map observations and instructions to actions, but a complete task trajectory carries more than action supervision. It also encodes which object parts must be contacted, how the arms coordinate, and what physical state one operation establishes for the next.

The challenge is to recover that structure from multimodal demonstrations without phase annotations, then align it across demonstrations that switch hands, skip already satisfied steps, or follow alternative valid paths. Situated Learning turns this evidence into a task-specific execution representation that prepares heterogeneous skills offline and coordinates their transitions at deployment.

Demonstrations

Provide action supervision together with task structure and local control references. The trajectory shows what was done, what was contacted, and how one operation prepared the next.

Situation

Organizes demonstrated paths into phase contracts with goals, conditions, outcomes, skills, and references. Compatible operations are aligned while alternative observed paths remain available.

Situated Agent

Selects a demonstrated path, invokes the assigned skill, and checks the physical outcome before advancing. It can continue when the handoff is satisfied, or retry and recover when it is not.
